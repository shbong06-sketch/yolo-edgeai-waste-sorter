# SO-ARM101 Description

ROS 2 description package containing the SO-ARM101 URDF and its runtime mesh assets.

## Resources

- `urdf/so_arm101.urdf`: robot kinematic and dynamic model
- `urdf/assets/`: STL files referenced by the URDF

The source assets were copied from the workspace-level `trs_so101` directory.
Generated Isaac Sim USD files and CAD `.part` sources remain in that original directory and are not installed by this package.
